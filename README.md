# 一括破壊 (Ikkatu Hakai)

Minecraft 1.21.5 用の mod です。木の幹を一括で破壊できる機能を追加します。

## 機能

- 木の幹を破壊すると、繋がっている木の幹も自動的に破壊されます
- 斜めに繋がっている木の幹も一括で破壊できます
- 対応している木の種類：
  - オーク
  - マツ
  - シラカバ
  - ジャングル
  - アカシア
  - ダークオーク
  - マングローブ
  - チェリー
  - ペールオーク

## インストール方法

1. [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/)をインストール
2. `.minecraft/mods`フォルダに mod ファイルを配置
3. Minecraft を起動

## ライセンス

この mod は個人使用のみを許可します。
再配布、商用利用、改変は禁止されています。
